# IIoT and Introduction to Data Analytics

## IIoT

**IIoT (Industrial Internet of Things)** means connecting industrial machines, sensors, and devices through a network to collect and exchange data.

Sensors can collect information such as:

* Temperature
* Pressure
* Speed
* Vibration
* Power consumption
* Machine status

### Basic Working

**Machine → Sensor → Network → Data → Analysis → Decision**

### Uses of IIoT

* Machine monitoring
* Predictive maintenance
* Production monitoring
* Quality control
* Energy management
* Cost reduction

**Example:**
A temperature sensor detects that a machine is overheating and sends an alert before the machine fails.

---

## Data Analytics

**Data Analytics** is the process of collecting, cleaning, processing, and analyzing data to find useful information and insights for better decision-making.

### Basic Process

**Data Collection → Data Cleaning → Data Processing → Data Analysis → Insights → Decision**

### Examples of Data Sources

* Excel files
* Databases
* Websites
* Sensors
* Applications
* Surveys

---

## Types of Data Analytics

| Type             | Question           | Purpose                 |
| ---------------- | ------------------ | ----------------------- |
| **Descriptive**  | What happened?     | Understand past data    |
| **Diagnostic**   | Why did it happen? | Find the reason         |
| **Predictive**   | What may happen?   | Predict future outcomes |
| **Prescriptive** | What should we do? | Suggest actions         |

---

## IIoT and Data Analytics Together

IIoT **collects data** from machines and sensors, while Data Analytics **analyzes that data** to generate useful insights.

**Example:**

A sensor records increasing machine temperature → IIoT collects the data → Data Analytics identifies the abnormal trend → System sends a maintenance alert.

### Key Difference

**IIoT = Data Collection**

**Data Analytics = Data Analysis & Insights**
